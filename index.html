درباره این پلتفرم

این وب‌سایت یک منبع آموزشی مستقل و فارسی برای یادگیری Django REST Framework است و مستندات رسمی یا ترجمه رسمی پروژه Django REST Framework محسوب نمی‌شود. تمام متن‌ها، مثال‌ها، تمرین‌ها و طراحی این پلتفرم به‌صورت مستقل تولید شده‌اند.

منابع رسمی

  • Django REST Framework — مستندات رسمی
  • Django — مستندات رسمی
  • Python — مستندات رسمی

Django و Django REST Framework پروژه‌های متن‌باز تحت مجوز BSD هستند و نام‌ها، کلاس‌ها و APIهای عمومی آن‌ها متعلق به پروژه و مشارکت‌کنندگان آن است. این پلتفرم هیچ ادعایی درباره مالکیت آن‌ها ندارد.

نسخه ۱.۰.۰ · هدف آموزشی: Python 3.11+ / Django 5.0+ / DRF 3.15+
