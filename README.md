# DRF فارسی — پلتفرم آموزشی

یک پلتفرم آموزشی مستقل و فارسی برای یادگیری Django REST Framework از صفر تا تولید.

## راه‌اندازی

به‌دلیل استفاده از `fetch()` برای بارگذاری فایل‌های JSON، این پروژه باید از طریق یک وب‌سرور محلی اجرا شود.

### روش ۱ — Python

```bash
cd drf-fa-platform
python -m http.server 8000
```
سپس در مرورگر: http://localhost:8000

### روش ۲ — Node
```bash
npx serve drf-fa-platform
```
